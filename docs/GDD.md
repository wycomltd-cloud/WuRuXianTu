# GDD｜遊戲設計文件

## 核心體驗

玩家是偶然踏入仙途的凡人，在九次閉關中反覆面對「繼續抽取」或「見好就收」的抉擇。乾坤袋會隨購買逐漸成長；強力靈藥提升回報，丹毒則令貪念變得危險。

## 勝利目標

第九回合後，修為板、剩餘晶石、中上品資源與丹毒共同構成最終修為，最高者突破「築基大圓滿」。

## 核心循環

1. 煉丹：抽取乾坤袋並決定是否停手。
2. 機緣：抽卡與擲骰，承受成功、平安或失敗結果。
3. 結算：依丹爐格位取得修為、靈石與晶石。
4. 黑市場：投資新藥材，改變往後各回合的乾坤袋。

## 設計支柱

- 貪念：多抽一枚可能得分，也可能炸爐。
- 成長：購買的資源永久加入袋中。
- 機緣：隨機事件帶來故事及玩家互動。
- 九回合：固定長度，讓策略有明確終點。

完整數值以 `rules/` 三份原始文件為準。
