# 規則待確認清單

V1.0 不修改作者規則。以下資料在三份來源文件中未完整定義，因此程式採明確標記的暫定行為。

1. **丹爐格位獎勵表缺少。** 暫用：修為 `floor(格位/4)`、靈石 `2 + floor(格位/3)`、到達 8 格獲晶石 1。正式格位表確定後應集中替換。
2. **冰魄蓮起始數量未寫明。** 原型暫設每人 1 株以顯示狀態；V1.0 尚未自動觸發重抽。
3. **特殊雙人機緣。** V1.0 顯示卡面結果，完整雙人擲骰與左側玩家影響排入 V1.1。
4. **同分決鬥。** 原規則要求重複盲抽 5 枚直到分勝負；V1.0 只按總分排序。
5. **起始丹毒數量。** 本次完整規則為丹毒 1×4、丹毒 2×2、丹毒 3×1；程式依此版本，不採舊對話中的 2×1。
